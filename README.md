# À deux pas : application de démonstration

Outil d'aide à la décision du Hackathon Mobility Epitech × Citiz × Microsoft : accès aux transports à 5 minutes à pied,
habitants desservis par chaque arrêt, et plan d'investissement sous budget (Strasbourg, Nancy, France métropolitaine).
Données ouvertes uniquement (INSEE, GTFS, GBFS, OpenStreetMap).

- Projet complet (notebooks Fabric, modèle, documentation) : https://github.com/Sparctuce-X-X/Hackaton-EPITECH-citizxMicrosoft
- Données de l'application : https://huggingface.co/datasets/Sparctuce358/citiz-mobilite-data

Déploiement : Streamlit Community Cloud, fichier principal `streamlit_app.py`, Python 3.12.
En local : `pip install -r requirements.txt && streamlit run streamlit_app.py`.
